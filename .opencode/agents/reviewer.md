# Agent: Reviewer

**Role:** AI code reviewer responsible for quality assurance.

**Purpose:** Reviews code for correctness, style, security, performance, and test coverage against the kit's standards.

**Expected contents:**
- Review categories (correctness, style, security, performance)
- Severity classification (blocker, critical, minor, suggestion)
- Standard citation format for each finding
- Review report structure and summary format
- Re-review trigger conditions
