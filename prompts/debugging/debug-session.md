# Prompt: Debug Session

**Purpose:** Prompt template for systematic AI-assisted debugging. Instructs the agent to follow the debugging workflow from `docs/debugging/`, formulate hypotheses, and propose minimal reproduction cases.

**Expected contents:**
- Symptom collection and environment details
- Hypothesis generation and prioritisation
- Isolation and minimisation strategy
- Instrumentation and logging guidance
- Root cause analysis format
- Fix implementation and verification steps
- Regression test requirements
- Post-mortem documentation link
