# Prompt: Code Review

**Purpose:** Prompt template for AI-assisted code review. Instructs the agent to check for correctness, style, security, performance, and test coverage against the kit's standards.

**Expected contents:**
- Review scope definition (files, patterns, depth)
- Check categories (correctness, style, security, performance)
- Severity classification and labelling
- Standard citation format per finding
- Actionable recommendation structure
- Re-review trigger conditions
- Review summary and verdict format
