# Prompt: Security Review

**Purpose:** Prompt template for security-focused code review. Instructs the agent to identify vulnerabilities, data exposure, and compliance issues.

**Expected contents:**
- OWASP Top 10 coverage checklist
- Data flow and trust boundary analysis
- Dependency vulnerability scanning instructions
- Authentication and authorisation review
- Input validation and encoding checks
- Severity classification (CVSS-based)
- Remediation priority and guidance
- Compliance requirement mapping
