# Prompt: Implement Feature

**Purpose:** Prompt template for implementing a feature from a specification. Instructs the AI agent to follow language-specific coding standards, write tests, and verify correctness.

**Expected contents:**
- Spec linking and requirement traceability
- Language-specific coding standard enforcement
- Test-driven implementation guidelines
- Test generation requirements (unit + integration)
- Self-review and verification checklist
- Documentation update requirements
- Performance and security considerations
