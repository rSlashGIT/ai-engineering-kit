# Prompt: Write Specification

**Purpose:** Prompt template for generating a detailed technical specification from a high-level requirement. Ensures consistent structure and coverage.

**Expected contents:**
- Context gathering and requirement synthesis
- Functional and non-functional requirement format
- Acceptance criteria generation (Given/When/Then)
- Edge case identification checklist
- API contract and data model specification
- Out-of-scope documentation
- Review and validation criteria
