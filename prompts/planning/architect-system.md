# Prompt: Architect System

**Purpose:** Prompt template for instructing an AI agent to act as a software architect. Used during the planning phase to produce architecture designs, ADRs, and system diagrams.

**Expected contents:**
- Context injection points (project brief, constraints, existing architecture)
- Output format requirements (ADRs, system diagrams, component specs)
- Constraint and trade-off specification format
- Review criteria and evaluation rubric
- Stakeholder consideration prompts
- Technology selection decision framework
