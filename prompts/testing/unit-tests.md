# Prompt: Write Unit Tests

**Purpose:** Prompt template for generating unit tests. Ensures edge case coverage, proper mocking, and adherence to the project's testing standards.

**Expected contents:**
- Coverage targets and measurement methodology
- Boundary and edge case analysis guidelines
- Mocking and isolation strategy
- Test structure (Arrange/Act/Assert)
- Naming conventions and organisation
- Test fixture and factory guidelines
- Property-based testing considerations
