# Prompt: Deploy Service

**Purpose:** Prompt template for planning and executing a service deployment. Ensures rollout strategy, rollback planning, health checks, and monitoring are considered before any deployment.

**Expected contents:**
- Environment and infrastructure context injection
- Deployment strategy selection (blue/green, canary, rolling)
- Health check and validation criteria
- Rollback procedure definition
- Monitoring and alerting setup instructions
- Post-deployment verification steps
