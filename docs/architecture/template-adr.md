# Architecture Decision Record (ADR) — Template

**Purpose:** Template for documenting architecture decisions using the ADR format. Each ADR captures a decision, its context, consequences, and alternatives considered.

**Expected contents:**
- Status (proposed, accepted, deprecated, superseded)
- Context and problem statement
- Decision description
- Consequences (positive and negative)
- Pros/cons analysis
- Alternatives considered
- References and related ADRs
- Numbering and versioning convention
