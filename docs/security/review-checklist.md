# Security Review — Checklist

**Purpose:** Security review checklist for code reviews and architecture reviews. Covers authentication, authorisation, input validation, data protection, dependency management, and logging.

**Expected contents:**
- Authentication and session management checks
- Authorisation and privilege escalation checks
- Input validation and output encoding
- Data protection (encryption, masking, minimisation)
- Dependency and supply chain security
- Logging, monitoring, and incident response
- OWASP Top 10 coverage mapping
- Language-specific security pitfalls
