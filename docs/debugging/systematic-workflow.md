# Systematic Debugging — Workflow

**Purpose:** A step-by-step debugging workflow that minimises guesswork. Covers hypothesis formulation, isolation techniques, instrumentation, root cause analysis, and fix verification.

**Expected contents:**
- Symptom collection and reproduction
- Hypothesis formulation and prioritisation
- Isolation techniques (binary search, logging, minimal reproduction)
- Root cause analysis methodology
- Fix implementation and verification
- Regression test requirements
- Post-mortem documentation template
- Integration with prompts/debugging/
