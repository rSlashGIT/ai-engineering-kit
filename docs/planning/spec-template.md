# Specification — Template

**Purpose:** Detailed technical specification template. Used to describe individual features, components, or modules with acceptance criteria, API contracts, and data models.

**Expected contents:**
- Context and motivation
- Functional requirements (must-have, nice-to-have)
- Non-functional requirements (performance, scalability, security)
- API surface definition (endpoints, contracts, errors)
- Data model and schema definitions
- Edge case catalogue
- Acceptance criteria (BDD-style scenarios)
- Out-of-scope clarifications
