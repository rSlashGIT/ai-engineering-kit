# Standard — Architecture

**Purpose:** Architecture principles, design patterns, and decision-making framework. Defines how architectural decisions are documented, reviewed, and evolved over time.

**Expected contents:**
- Architecture principles (SOLID, DRY, YAGNI, CQRS, etc.)
- Decision-making framework and ADR format
- System design review process
- Coupling and cohesion guidelines
- Scalability, reliability, and availability requirements
- Integration patterns and API design rules
- Technology selection criteria
