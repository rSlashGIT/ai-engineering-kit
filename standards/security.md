# Standard — Security

**Purpose:** Security rules and requirements for all projects. Covers authentication, authorisation, data protection, input validation, dependency management, and secure development lifecycle.

**Expected contents:**
- Authentication and authorisation standards
- Input validation and sanitisation rules
- Data encryption requirements (at rest and in transit)
- Dependency vulnerability management
- Secrets management guidelines
- Logging and monitoring security requirements
- Secure development lifecycle (SDLC) integration
