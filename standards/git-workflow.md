# Standard — Git Workflow

**Purpose:** Git branching strategy, commit message conventions, and PR workflow. Defines how changes flow from development to production.

**Expected contents:**
- Branch naming convention (feat/, fix/, chore/, docs/, refactor/)
- Commit message format (Conventional Commits)
- PR size and scope guidelines
- Review and approval requirements
- Merge strategy (squash, merge, rebase)
- Release branching model (GitFlow, trunk-based, etc.)
- Tagging and versioning convention
