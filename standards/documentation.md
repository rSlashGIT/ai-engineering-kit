# Standard — Documentation

**Purpose:** Rules for what to document, how to write it, and where to place it. Covers README, API docs, architecture docs, and inline documentation.

**Expected contents:**
- Documentation matrix (what, where, when to document)
- README requirements and template
- API documentation conventions
- Architecture documentation rules (ADRs)
- Comment vs documentation guidelines
- Diagram and visual documentation standards
- Documentation review and maintenance requirements
