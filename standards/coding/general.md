# Coding Standard — General

**Purpose:** Language-agnostic coding conventions: naming, file organisation, error handling, logging, and code structure. All language-specific standards extend this document.

**Expected contents:**
- Naming conventions (variables, functions, classes, constants)
- File and directory organisation rules
- Error handling patterns (exceptions, results, panics)
- Logging and observability guidelines
- Code organisation principles (single responsibility, cohesion)
- Comment and documentation expectations
- Code review expectations and gate criteria
