# Coding Standard — Rust

**Purpose:** Rust-specific coding conventions extending the general standard. Covers formatting, error handling, unsafe code policy, and tooling (rustfmt, clippy, cargo test).

**Expected contents:**
- Tooling recommendations (rustfmt, clippy, cargo test)
- Error handling patterns (thiserror, anyhow, custom errors)
- Unsafe code restrictions and justification requirements
- Module and crate organisation conventions
- Testing conventions (unit, integration, doc-tests)
- Feature flag and conditional compilation guidelines
- Documentation requirements (rustdoc)
