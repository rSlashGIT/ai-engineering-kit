# Standard — Testing

**Purpose:** Testing pyramid, coverage requirements, test naming conventions, and test structure. Applies to unit, integration, and end-to-end tests.

**Expected contents:**
- Testing pyramid and distribution guidelines
- Coverage thresholds (unit, integration, e2e)
- Test file organisation and naming
- Naming conventions for test cases
- Mocking and faking guidelines
- CI integration and test execution requirements
- Flaky test management policy
- Performance and load testing expectations
